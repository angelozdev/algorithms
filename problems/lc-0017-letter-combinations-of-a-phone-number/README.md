# 17. Letter Combinations of a Phone Number

## Statement

You're given a string of digits, each one between `2` and `9`. On an old telephone keypad, every digit lights up a handful of letters (digit `1` has none). Build every letter string you can get by choosing one letter for each digit, in the digits' order, and return them in any order.

**Examples**

- `digits = "23"` → `["ad","ae","af","bd","be","bf","cd","ce","cf"]`
- `digits = "2"` → `["a","b","c"]`

**Constraints:** `1 <= digits.length <= 4` · each digit in `digits` falls between `2` and `9`
