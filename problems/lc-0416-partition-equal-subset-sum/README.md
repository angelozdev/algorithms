# 416. Partition Equal Subset Sum

## Statement

You're handed an integer array `nums`. Decide whether its values can be divided into two groups that add up to the same total, and report that as `true` or `false`.

**Examples**

- `nums = [1,5,11,5]` → `true` (`[1,5,5]` and `[11]`)
- `nums = [1,2,3,5]` → `false`

**Constraints:** `1 <= nums.length <= 200` · `1 <= nums[i] <= 100`
