# 84. Largest Rectangle in Histogram

## Statement

You're given an array `heights` describing a histogram, where each bar is one unit wide. Find the area of the largest rectangle that fits inside the histogram, using one or more consecutive bars and bounded by the height of the shortest bar in that span.

**Examples**

- `heights = [2,1,5,6,2,3]` → `10`
- `heights = [2,4]` → `4`

**Constraints:** `1 <= heights.length <= 10^5` · `0 <= heights[i] <= 10^4`
