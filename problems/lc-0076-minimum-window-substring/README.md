# 76. Minimum Window Substring

## Statement

Given strings `s` and `t`, find the shortest contiguous substring of `s` that contains every character of `t`, counting repeated characters. Return the empty string if no such substring exists. The inputs are set up so that, when an answer exists, it is unique.

**Examples**

- `s = "ADOBECODEBANC", t = "ABC"` → `"BANC"`
- `s = "a", t = "a"` → `"a"`
- `s = "a", t = "aa"` → `""`

**Constraints:** `1 <= s.length, t.length <= 10^5` · `s` and `t` consist of uppercase and lowercase English letters
