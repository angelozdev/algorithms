# 704. Binary Search

## Statement

You get an array `nums` of distinct integers sorted in ascending order, and an integer `target`. Find and return the index of `target` in `nums`. If `target` is not in the array, return `-1`.

**Examples**

- `nums = [-1,0,3,5,9,12], target = 9` → `4`
- `nums = [-1,0,3,5,9,12], target = 2` → `-1`

**Constraints:** `1 <= nums.length <= 10^4` · `-10^4 < nums[i], target < 10^4` · all values in `nums` are unique and sorted in ascending order
