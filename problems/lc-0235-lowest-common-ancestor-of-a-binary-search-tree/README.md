# 235. Lowest Common Ancestor of a Binary Search Tree

## Statement

You're given a binary search tree and two of its existing nodes, `p` and `q`. Find their lowest common ancestor: the deepest node in the tree that has both `p` and `q` among its descendants, where a node counts as a descendant of itself. Node values are unique, and `p` and `q` are guaranteed to be two different nodes already present in the tree.

**Examples**

- `root = [6,2,8,0,4,7,9,null,null,3,5], p = 2, q = 8` → `6`
- `root = [6,2,8,0,4,7,9,null,null,3,5], p = 2, q = 4` → `2`
- `root = [2,1], p = 2, q = 1` → `2`

**Constraints:** the number of nodes is in `[2, 10^5]` · `-10^9 <= Node.val <= 10^9`, all unique · `p != q` · `p` and `q` both exist in the tree
