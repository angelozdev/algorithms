# 79. Word Search

## Statement

You're given an `m x n` grid of single letters and a target word. Starting from any cell, trace a path through side-sharing neighbors (up, down, left, right), matching the word one letter at a time, without reusing a cell already in the path. Return whether some path spells out the whole word.

**Examples**

- `board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "ABCCED"` → `true`
- `board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "SEE"` → `true`
- `board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "ABCB"` → `false`

**Constraints:** `m == board.length` · `n == board[i].length` · `1 <= m, n <= 6` · `1 <= word.length <= 15` · `board` and `word` contain only English letters, upper or lower case
