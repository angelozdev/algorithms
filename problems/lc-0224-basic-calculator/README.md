# 224. Basic Calculator

## Statement

You're given a string `s` that represents a valid arithmetic expression built from non-negative integers, `+`, `-`, parentheses, and spaces. Evaluate it and return the result. A `-` may act as a unary sign (such as `-5` or `-(2 + 3)`), but `+` never does. You may not use a built-in expression evaluator (such as `eval`) — parse and compute the value yourself.

**Examples**

- `s = "1 + 1"` → `2`
- `s = " 2-1 + 2 "` → `3`
- `s = "(1+(4+5+2)-3)+(6+8)"` → `23`

**Constraints:** `1 <= s.length <= 3 * 10^5` · `s` consists of digits, `+`, `-`, `(`, `)`, and spaces · the input is always a valid expression with no two consecutive operators · every number and running calculation fits in a signed 32-bit integer
