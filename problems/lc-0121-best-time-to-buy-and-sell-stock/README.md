# 121. Best Time to Buy and Sell Stock

## Statement

You get a list of a stock's price on each day. Pick one day to buy and a later day to sell, with the goal of making the largest possible profit from that single trade. When no trade would earn money, the answer is `0`.

**Examples**

- `prices = [7,1,5,3,6,4]` → `5`
- `prices = [7,6,4,3,1]` → `0`

**Constraints:** `1 <= prices.length <= 10^5` · `0 <= prices[i] <= 10^4`
