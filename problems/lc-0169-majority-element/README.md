# 169. Majority Element

## Statement

You're given an array of `n` numbers, and you're told one value shows up more than `n / 2` times (so it's guaranteed to exist). Find and return that value.

**Examples**

- `nums = [3,2,3]` → `3`
- `nums = [2,2,1,1,1,2,2]` → `2`

**Constraints:** `n == nums.length` · `1 <= n <= 5 * 10^4` · `-10^9 <= nums[i] <= 10^9` · a majority element is guaranteed to exist
