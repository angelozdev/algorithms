# 206. Reverse Linked List

## Statement

You are given the head of a singly linked list. Flip the order of its nodes so the list runs from tail to head, and return the head of that flipped list. An empty list stays empty.

**Examples**

- `head = [1,2,3,4,5]` → `[5,4,3,2,1]`
- `head = [1,2]` → `[2,1]`
- `head = []` → `[]`

**Constraints:** `0 <= number of nodes <= 5000` · `-5000 <= Node.val <= 5000`
