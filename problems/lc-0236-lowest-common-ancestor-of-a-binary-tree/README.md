# 236. Lowest Common Ancestor of a Binary Tree

## Statement

You're given a binary tree — not necessarily a search tree — and two of its existing nodes, `p` and `q`. Find their lowest common ancestor: the deepest node that has both `p` and `q` among its descendants, where a node counts as a descendant of itself. Node values are unique, and `p` and `q` are guaranteed to be two different nodes already present in the tree.

**Examples**

- `root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1` → `3`
- `root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 4` → `5`
- `root = [1,2], p = 1, q = 2` → `1`

**Constraints:** the number of nodes is in `[2, 10^5]` · `-10^9 <= Node.val <= 10^9`, all unique · `p != q` · `p` and `q` both exist in the tree
