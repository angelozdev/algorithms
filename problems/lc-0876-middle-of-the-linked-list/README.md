# 876. Middle of the Linked List

## Statement

You are given the head of a singly linked list. Return its middle node. When the list has an even number of nodes, return the second of the two middle nodes.

**Examples**

- `head = [1,2,3,4,5]` → `[3,4,5]`
- `head = [1,2,3,4,5,6]` → `[4,5,6]`

**Constraints:** `1 <= number of nodes <= 100` · `1 <= Node.val <= 100`
