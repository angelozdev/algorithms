# 230. Kth Smallest Element in a BST

## Statement

You're handed a binary search tree together with a number `k`. Line up every value stored in the tree in increasing order, then return the value sitting at position `k` of that line, counting the first position as `1`.

**Examples**

- `root = [3,1,4,null,2], k = 1` → `1`
- `root = [5,3,6,2,4,null,null,1], k = 3` → `3`

**Constraints:** the tree has `n` nodes · `1 <= k <= n <= 10^4` · `0 <= Node.val <= 10^4`
