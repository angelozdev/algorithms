# 56. Merge Intervals

## Statement

You're given a list of intervals, each written as `[start, end]`. Whenever two or more intervals overlap (they share at least one point), combine them into a single interval spanning all of them. Return the resulting intervals, covering the same total range as the input.

**Examples**

- `intervals = [[1,3],[2,6],[8,10],[15,18]]` → `[[1,6],[8,10],[15,18]]`
- `intervals = [[1,4],[4,5]]` → `[[1,5]]`
- `intervals = [[4,7],[1,4]]` → `[[1,7]]`

**Constraints:** `1 <= intervals.length <= 10^4` · `intervals[i].length == 2` · `0 <= start_i <= end_i <= 10^4`
