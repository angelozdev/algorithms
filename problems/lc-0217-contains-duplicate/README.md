# 217. Contains Duplicate

## Statement

Given an array of integers, say whether any value shows up more than once. Return `true` as soon as a repeated value exists, or `false` if every element is unique.

**Examples**

- `nums = [1,2,3,1]` → `true`
- `nums = [1,2,3,4]` → `false`
- `nums = [1,1,1,3,3,4,3,2,4,2]` → `true`

**Constraints:** `1 <= nums.length <= 10^5` · `-10^9 <= nums[i] <= 10^9`
