# 125. Valid Palindrome

## Statement

Given a string, decide whether it reads the same forwards and backwards once you lowercase every letter and drop any character that isn't a letter or digit. Letters and digits both count as alphanumeric. Return `true` or `false` accordingly.

**Examples**

- `s = "A man, a plan, a canal: Panama"` → `true`
- `s = "race a car"` → `false`
- `s = " "` → `true`

**Constraints:** `1 <= s.length <= 2 * 10^5` · `s` consists only of printable ASCII characters
