# 297. Serialize and Deserialize Binary Tree

## Statement

Design a way to turn a binary tree into a single string and back again, so that decoding your string reproduces a tree with the same shape and the same node values as the original. The exact text format is entirely up to you. The judge only checks that encoding and then decoding a tree returns an equivalent tree; it never inspects the string itself.

**Examples**

- `root = [1,2,3,null,null,4,5]` → `[1,2,3,null,null,4,5]`
- `root = []` → `[]`

**Constraints:** the number of nodes is in `[0, 10^4]` · `-1000 <= Node.val <= 1000`
