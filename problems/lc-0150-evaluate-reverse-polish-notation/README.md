# 150. Evaluate Reverse Polish Notation

## Statement

You are given a list of tokens that together spell out an arithmetic expression written in Reverse Polish (postfix) notation. Evaluate the expression and return the resulting integer. Each token is either one of the operators `+`, `-`, `*`, `/` or an integer operand, division always truncates toward zero, and the input never divides by zero.

**Examples**

- `tokens = ["2","1","+","3","*"]` → `9`
- `tokens = ["4","13","5","/","+"]` → `6`
- `tokens = ["10","6","9","3","+","-11","*","/","*","17","+","5","+"]` → `22`

**Constraints:** `1 <= tokens.length <= 10^4` · each token is `+`, `-`, `*`, `/`, or an integer in `[-200, 200]` · the expression is always valid, and every intermediate result fits in a 32-bit integer
