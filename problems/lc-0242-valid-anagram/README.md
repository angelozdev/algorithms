# 242. Valid Anagram

## Statement

Given two strings, decide whether the second one is an anagram of the first: the same letters, the same number of times, just rearranged. Return `true` if it is, `false` otherwise.

**Examples**

- `s = "anagram", t = "nagaram"` → `true`
- `s = "rat", t = "car"` → `false`

**Constraints:** `1 <= s.length, t.length <= 5 * 10^4` · `s` and `t` consist of lowercase English letters

**Follow-up:** How would your approach change if the strings could contain Unicode characters?
