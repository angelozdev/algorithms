# 3. Longest Substring Without Repeating Characters

## Statement

Given a string `s`, return the length of its longest contiguous run of characters that never repeats a character. A substring must be made of consecutive characters from `s` (unlike a subsequence, which may skip characters).

**Examples**

- `s = "abcabcbb"` → `3`
- `s = "bbbbb"` → `1`
- `s = "pwwkew"` → `3`

**Constraints:** `0 <= s.length <= 10^5` · `s` consists of English letters, digits, symbols and spaces
