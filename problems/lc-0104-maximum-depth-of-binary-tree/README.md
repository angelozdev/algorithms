# 104. Maximum Depth of Binary Tree

## Statement

You get the root of a binary tree. Counting nodes, find how far the tree's farthest leaf sits from the root along its own branch, then return that count as the tree's maximum depth.

**Examples**

- `root = [3,9,20,null,null,15,7]` → `3`
- `root = [1,null,2]` → `2`

**Constraints:** the tree has `0` to `10^4` nodes · `-100 <= Node.val <= 100`
