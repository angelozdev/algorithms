# 438. Find All Anagrams in a String

## Statement

Given two strings `s` and `p`, return every start index in `s` where the substring of that length is an anagram of `p` — the same letters, the same number of times each, in any arrangement. The indices may come back in any order.

**Examples**

- `s = "cbaebabacd", p = "abc"` → `[0,6]`
- `s = "abab", p = "ab"` → `[0,1,2]`

**Constraints:** `1 <= s.length, p.length <= 3 * 10^4` · `s` and `p` consist of lowercase English letters
