# 11. Container With Most Water

## Statement

You get an array `height` where `height[i]` is the height of a vertical line standing at position `i`. Picking any two of those lines as the walls of a container (with the x-axis as the floor) traps some amount of water between them; the container cannot be tilted. Return the largest amount of water any such pair of lines can hold.

**Examples**

- `height = [1,8,6,2,5,4,8,3,7]` → `49`
- `height = [1,1]` → `1`

**Constraints:** `n == height.length` · `2 <= n <= 10^5` · `0 <= height[i] <= 10^4`
