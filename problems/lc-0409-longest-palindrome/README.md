# 409. Longest Palindrome

## Statement

Given a string of lowercase and/or uppercase letters, find the length of the longest palindrome you could rearrange its letters into (you don't need to use every letter). Letters are case sensitive, so `"Aa"` does not count as a palindrome.

**Examples**

- `s = "abccccdd"` → `7` (one such palindrome is `"dccaccd"`)
- `s = "a"` → `1`

**Constraints:** `1 <= s.length <= 2000` · `s` consists of lowercase and/or uppercase English letters only
