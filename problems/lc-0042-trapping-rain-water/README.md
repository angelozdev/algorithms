# 42. Trapping Rain Water

## Statement

You're given a row of bars with non-negative heights, each one unit wide, described by the array `height`. After it rains, water settles into the dips between taller bars on either side. Compute the total amount of water the whole elevation map traps.

**Examples**

- `height = [0,1,0,2,1,0,1,3,2,1,2,1]` → `6`
- `height = [4,2,0,3,2,5]` → `9`

**Constraints:** `n == height.length` · `1 <= n <= 2 * 10^4` · `0 <= height[i] <= 10^5`
