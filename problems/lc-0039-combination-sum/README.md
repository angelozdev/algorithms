# 39. Combination Sum

## Statement

You're given an array of distinct positive integers `candidates` and a target integer `target`. Find every unique group of chosen numbers, reusing any candidate as many times as you like, that adds up exactly to `target`. Two groups only count as different when some candidate shows up a different number of times. Return the groups in any order; at most 150 of them exist for any input the judge will give you.

**Examples**

- `candidates = [2,3,6,7], target = 7` → `[[2,2,3],[7]]`
- `candidates = [2,3,5], target = 8` → `[[2,2,2,2],[2,3,3],[3,5]]`
- `candidates = [2], target = 1` → `[]`

**Constraints:** `1 <= candidates.length <= 30` · `2 <= candidates[i] <= 40` · every element of `candidates` is distinct · `1 <= target <= 40`
