# 543. Diameter of Binary Tree

## Statement

You get the root of a binary tree. Among every pair of nodes in the tree, find the pair whose connecting path is longest, counted by the number of edges on it — that path does not need to pass through the root. Return that longest edge count, the tree's diameter.

**Examples**

- `root = [1,2,3,4,5]` → `3` (the path `[4,2,1,3]` or `[5,2,1,3]`)
- `root = [1,2]` → `1`

**Constraints:** the tree has `1` to `10^4` nodes · `-100 <= Node.val <= 100`
