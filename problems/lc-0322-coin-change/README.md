# 322. Coin Change

## Statement

You have coins in a set of denominations given by `coins`, with an unlimited supply of each, and a target `amount`. Return the smallest number of coins that add up exactly to `amount`, or `-1` if no combination of the coins reaches it.

**Examples**

- `coins = [1,2,5], amount = 11` → `3` (5 + 5 + 1)
- `coins = [2], amount = 3` → `-1`
- `coins = [1], amount = 0` → `0`

**Constraints:** `1 <= coins.length <= 12` · `1 <= coins[i] <= 2^31 - 1` · `0 <= amount <= 10^4`
