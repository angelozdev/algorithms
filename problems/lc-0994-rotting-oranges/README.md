# 994. Rotting Oranges

## Statement

You're given a grid where each cell holds an empty cell (`0`), a fresh orange (`1`), or a rotten orange (`2`). Every minute, any fresh orange sharing a side with a rotten one also becomes rotten. Return the number of minutes until no fresh orange remains, or `-1` if some fresh orange can never be reached.

**Examples**

- `grid = [[2,1,1],[1,1,0],[0,1,1]]` → `4`
- `grid = [[2,1,1],[0,1,1],[1,0,1]]` → `-1`
- `grid = [[0,2]]` → `0`

**Constraints:** `m == grid.length` · `n == grid[i].length` · `1 <= m, n <= 10` · `grid[i][j]` is `0`, `1`, or `2`
