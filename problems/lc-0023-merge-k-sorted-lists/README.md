# 23. Merge k Sorted Lists

## Statement

You are given an array of linked lists, where each list is already sorted in ascending order. Combine the nodes of every list into one linked list that stays sorted ascending, and return its head. The array itself may be empty, and any of its lists may be empty too.

**Examples**

- `lists = [[1,4,5],[1,3,4],[2,6]]` → `[1,1,2,3,4,4,5,6]`
- `lists = []` → `[]`
- `lists = [[]]` → `[]`

**Constraints:** `k == lists.length` · `0 <= k <= 10^4` · `0 <= lists[i].length <= 500` · `-10^4 <= lists[i][j] <= 10^4` · each `lists[i]` is sorted in ascending order · the sum of `lists[i].length` over all lists is at most `10^4`
