# 155. Min Stack

## Statement

Design a stack, called `MinStack`, that supports pushing a value, popping the value on top, reading the value on top, and reporting the smallest value currently stored in the stack. Every call to `pop`, `top` and `getMin` is guaranteed to happen on a non-empty stack.

**Examples**

- `["MinStack","push","push","push","getMin","pop","top","getMin"]`, `[[],[-2],[0],[-3],[],[],[],[]]` → `[null,null,null,null,-3,null,0,-2]`

**Constraints:** `-2^31 <= val <= 2^31 - 1` · `pop`, `top` and `getMin` are only ever called on a non-empty stack · at most `3 * 10^4` total calls to `push`, `pop`, `top` and `getMin`
