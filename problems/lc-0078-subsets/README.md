# 78. Subsets

## Statement

You're given an array of distinct integers. Return every subset of it, including the empty one and the full array, without listing the same subset twice. The subsets, and the numbers inside each one, may come back in any order.

**Examples**

- `nums = [1,2,3]` → `[[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]`
- `nums = [0]` → `[[],[0]]`

**Constraints:** `1 <= nums.length <= 10` · `-10 <= nums[i] <= 10` · every value in `nums` is distinct
