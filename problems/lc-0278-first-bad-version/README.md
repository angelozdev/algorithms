# 278. First Bad Version

## Statement

Versions of a product are numbered `1` through `n`, and once a version is bad, every version released after it is bad too. You're given a judge function `isBadVersion(version)` that reports whether a given version is bad, and must return the number of the first bad version. Calls to `isBadVersion` should be kept to a minimum.

**Examples**

- `n = 5, bad = 4` → `4`
- `n = 1, bad = 1` → `1`

**Constraints:** `1 <= bad <= n <= 2^31 - 1`
