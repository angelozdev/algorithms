# 226. Invert Binary Tree

## Statement

You get the root of a binary tree. Swap the left and right children of every node, so the whole tree becomes a mirror image of itself. Return the root of the inverted tree.

**Examples**

- `root = [4,2,7,1,3,6,9]` → `[4,7,2,9,6,3,1]`
- `root = [2,1,3]` → `[2,3,1]`
- `root = []` → `[]`

**Constraints:** the tree has `0` to `100` nodes · `-100 <= Node.val <= 100`
