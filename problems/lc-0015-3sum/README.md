# 15. 3Sum

## Statement

Given an integer array `nums`, return every triplet of values from `nums` (picked from three distinct positions) that adds up to `0`. The result must not contain the same triplet twice, and neither the order of the triplets nor the order of the three values inside a triplet matters.

**Examples**

- `nums = [-1,0,1,2,-1,-4]` → `[[-1,-1,2],[-1,0,1]]`
- `nums = [0,1,1]` → `[]`
- `nums = [0,0,0]` → `[[0,0,0]]`

**Constraints:** `3 <= nums.length <= 3000` · `-10^5 <= nums[i] <= 10^5`
