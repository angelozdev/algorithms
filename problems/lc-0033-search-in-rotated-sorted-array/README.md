# 33. Search in Rotated Sorted Array

## Statement

An array of distinct integers, sorted in ascending order, was rotated at some unknown pivot before being handed to you as `nums`. Given `nums` and an integer `target`, find and return the index of `target` in `nums`. Return `-1` if `target` is not present.

**Examples**

- `nums = [4,5,6,7,0,1,2], target = 0` → `4`
- `nums = [4,5,6,7,0,1,2], target = 3` → `-1`
- `nums = [1], target = 0` → `-1`

**Constraints:** `1 <= nums.length <= 5000` · `-10^4 <= nums[i] <= 10^4` · all values in `nums` are unique · `nums` is an ascending array that was possibly rotated · `-10^4 <= target <= 10^4`
