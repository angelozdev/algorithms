# 110. Balanced Binary Tree

## Statement

You get a binary tree and must say whether it is height-balanced: at every single node, the heights of its left and right subtrees never differ by more than one. Return `true` if the whole tree meets that rule, `false` otherwise.

**Examples**

- `root = [3,9,20,null,null,15,7]` → `true`
- `root = [1,2,2,3,3,null,null,4,4]` → `false`
- `root = []` → `true`

**Constraints:** the tree has `0` to `5000` nodes · `-10^4 <= Node.val <= 10^4`
