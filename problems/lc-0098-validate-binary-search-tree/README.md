# 98. Validate Binary Search Tree

## Statement

You get the root of a binary tree and must say whether it is a valid binary search tree. A tree is a valid BST when, for every node, its entire left subtree holds only values strictly less than the node's own value, its entire right subtree holds only values strictly greater, and both subtrees are themselves valid BSTs by that same rule.

**Examples**

- `root = [2,1,3]` → `true`
- `root = [5,1,4,null,null,3,6]` → `false` (the root's value is `5` but its right child's value is `4`)

**Constraints:** the tree has `1` to `10^4` nodes · `-2^31 <= Node.val <= 2^31 - 1`
