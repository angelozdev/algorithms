# 199. Binary Tree Right Side View

## Statement

You get the root of a binary tree. Picture yourself standing to its right: at every depth you can only see one node, the one furthest to the right at that depth. Return those visible values, ordered from the top level down to the bottom.

**Examples**

- `root = [1,2,3,null,5,null,4]` → `[1,3,4]`
- `root = [1,2,3,4,null,null,null,5]` → `[1,3,4,5]`
- `root = [1,null,3]` → `[1,3]`
- `root = []` → `[]`

**Constraints:** the tree has `0` to `100` nodes · `-100 <= Node.val <= 100`
