# 238. Product of Array Except Self

## Statement

You're given an integer array `nums`. Return a new array `answer` where `answer[i]` is the product of every element of `nums` except `nums[i]`. Every prefix or suffix product, and every value in the result, is guaranteed to fit in a 32-bit integer. Solve it without using the division operation.

**Examples**

- `nums = [1,2,3,4]` → `[24,12,8,6]`
- `nums = [-1,1,0,-3,3]` → `[0,0,9,0,0]`

**Constraints:** `2 <= nums.length <= 10^5` · `-30 <= nums[i] <= 30` · the input is generated so every `answer[i]` fits in a 32-bit integer
