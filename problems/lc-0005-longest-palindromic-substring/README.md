# 5. Longest Palindromic Substring

## Statement

Given a string `s`, return the longest contiguous substring of `s` that reads the same forwards and backwards. When more than one substring of that maximal length qualifies, any one of them is accepted.

**Examples**

- `s = "babad"` → `"bab"` or `"aba"` (both are valid)
- `s = "cbbd"` → `"bb"`

**Constraints:** `1 <= s.length <= 1000` · `s` consists only of digits and English letters
