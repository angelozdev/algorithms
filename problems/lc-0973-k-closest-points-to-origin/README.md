# 973. K Closest Points to Origin

## Statement

You're given a list of points on the 2D plane and an integer `k`. Return the `k` points that lie closest to the origin `(0, 0)`, measured by ordinary Euclidean distance. The points may come back in any order, and the set of `k` closest points is guaranteed to be unique even though their order is not.

**Examples**

- `points = [[1,3],[-2,2]], k = 1` → `[[-2,2]]`
- `points = [[3,3],[5,-1],[-2,4]], k = 2` → `[[3,3],[-2,4]]`

**Constraints:** `1 <= k <= points.length <= 10^4` · `-10^4 <= x_i, y_i <= 10^4`
