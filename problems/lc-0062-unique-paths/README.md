# 62. Unique Paths

## Statement

A robot starts at the top-left corner of an `m x n` grid and wants to reach the bottom-right corner. At each step it can only move one cell down or one cell right. Given `m` and `n`, return how many distinct paths lead the robot to the bottom-right corner. The answer for any input the judge gives you fits within `2 * 10^9`.

**Examples**

- `m = 3, n = 7` → `28`
- `m = 3, n = 2` → `3` (Right→Down→Down, Down→Down→Right, Down→Right→Down)

**Constraints:** `1 <= m, n <= 100` · the inputs are chosen so the answer is at most `2 * 10^9`
