# 53. Maximum Subarray

## Statement

You're given an integer array `nums`. Find a contiguous, non-empty subarray within it whose elements add up to the largest possible sum, and return that sum.

**Examples**

- `nums = [-2,1,-3,4,-1,2,1,-5,4]` → `6` (the subarray `[4,-1,2,1]` has the largest sum)
- `nums = [1]` → `1`
- `nums = [5,4,-1,7,8]` → `23`

**Constraints:** `1 <= nums.length <= 10^5` · `-10^4 <= nums[i] <= 10^4`
