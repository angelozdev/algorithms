# 102. Binary Tree Level Order Traversal

## Statement

You get the root of a binary tree. Group its node values by depth, each group listing its values left to right, and return the groups ordered from the root's level down to the deepest level.

**Examples**

- `root = [3,9,20,null,null,15,7]` → `[[3],[9,20],[15,7]]`
- `root = [1]` → `[[1]]`
- `root = []` → `[]`

**Constraints:** the tree has `0` to `2000` nodes · `-1000 <= Node.val <= 1000`
