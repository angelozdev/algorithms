# 232. Implement Queue using Stacks

## Statement

Build a first-in-first-out queue, called `MyQueue`, backed only by two stacks. It must support `push(x)` to add an element at the back, `pop()` to remove and return the element at the front, `peek()` to read the front element without removing it, and `empty()` to report whether the queue holds anything. You may rely only on a stack's standard operations: push, pop/peek at the top, checking its size, and checking whether it is empty.

**Examples**

- `["MyQueue", "push", "push", "peek", "pop", "empty"]`, `[[], [1], [2], [], [], []]` → `[null, null, null, 1, 1, false]`

**Constraints:** `1 <= x <= 9` · at most `100` total calls to `push`, `pop`, `peek` and `empty` · every call to `pop` and `peek` happens on a non-empty queue
