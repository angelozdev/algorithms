# 67. Add Binary

## Statement

You get two numbers written as binary strings. Add them together and return the result, also written as a binary string.

**Examples**

- `a = "11", b = "1"` → `"100"`
- `a = "1010", b = "1011"` → `"10101"`

**Constraints:** `1 <= a.length, b.length <= 10^4` · `a` and `b` only contain `'0'` or `'1'` · neither string has leading zeros, except for `"0"` itself
