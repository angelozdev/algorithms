# 70. Climbing Stairs

## Statement

A staircase has `n` steps and each move climbs either 1 or 2 steps. In how many distinct ways can you reach the top?

**Examples**

- `n = 2` → `2` (1+1, 2)
- `n = 3` → `3` (1+1+1, 1+2, 2+1)

**Constraints:** `1 <= n <= 45`
