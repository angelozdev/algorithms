# Sorted squares

## Statement

`nums` is sorted in non-decreasing order and may contain negative numbers. Return a new array with the square of every element, also sorted in non-decreasing order.

**Examples**

- `nums = [-3,-1,0,2]` → `[0,1,4,9]`
- `nums = [-5,-4,1,6]` → `[1,16,25,36]`
- `nums = [2,3,7]` → `[4,9,49]`

**Constraints:** `1 <= nums.length <= 10^5` · `-10^4 <= nums[i] <= 10^4` · `nums` is sorted in non-decreasing order

**Follow-up:** squaring and then sorting works. Can you build the answer in a single pass, without calling a sort?
