# Most frequent

## Statement

Return the value that appears most often in `nums`. If several values tie, return the smallest of them.

**Examples**

- `nums = [1,3,3,2,1,3]` → `3`
- `nums = [4,4,1,1]` → `1` (4 and 1 tie; 1 is smaller)
- `nums = [9]` → `9`

**Constraints:** `1 <= nums.length <= 10^5` · `-10^9 <= nums[i] <= 10^9`
